# HTTP report 0013: App options

Roadmap `docs/roadmap/0013-app-options.md`, step 11, against `docs/review/http-0013-baseline.md`.
Test binaries of `ee67bb2` (baseline) and `4650d46` (roadmap end) run alternately, six rounds, the order
swapped every round, compared with `benchstat`. Go 1.27.4, Intel Core i7-9750H, macOS.

## Hot path (`bench/`, no stage configured: today's default)

| Scenario | Before | After | |
|---|---|---|---|
| Static | 1.07 µs | 1.03 µs | ~ (p=0.39) |
| Param | 2.34 µs | 2.39 µs | ~ (p=0.24) |
| Query | 3.31 µs | 3.32 µs | ~ (p=0.73) |
| JSONBody | 4.73 µs | 4.96 µs | +4.9 % (p=0.015) |
| Chain | 2.91 µs | 2.89 µs | ~ (p=0.82) |
| Exception | 1.74 µs | 1.75 µs | ~ (p=0.59) |
| NotFound | 0.88 µs | 0.86 µs | ~ (p=0.18) |
| Page: JSON list | 8.58 µs | 8.70 µs | ~ (p=0.39) |
| Page: HTML list | 65.6 µs | 63.9 µs | ~ (p=0.24) |

- Allocations per request are identical in every scenario; bytes are identical except Chain (+15 B,
  +0.8 %) and the page scenarios (+0.1 to +0.3 %).
- JSONBody's +4.9 % is inside the baseline's own spread (± 4 %) and touches no code this roadmap
  changed (body binding); treat it as noise, recheck on a quiet machine with the next measurement.
- `BenchmarkPreRoute_None` allocates as much as `Static` (7): a disabled stage costs nothing.
