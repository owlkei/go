# HTTP report 0007: after the public API review

Roadmap `docs/roadmap/0007-public-api-review.md`, step 8. The roadmap moved packages and renamed names;
it changed no request-path algorithm, so this report only checks that nothing got slower.

## Method

- `bench/` `BenchmarkOwlkei/*` (end to end through `App.ServeHTTP`), Go 1.27.4, Intel Core i7-9750H, 12 threads.
- Before: `2647b71` (the start of the run). After: `f90b9db`. The two builds ran interleaved, six rounds
  of one run each, compared with `benchstat`.
- The machine was busy during the runs (other agents working): time has a spread of ±30-45 % per scenario,
  so time differences below that are not measurable here. Allocations are exact.

## Results

| Scenario | Time before → after | p | Bytes/op | Allocs/op |
|---|---|---|---|---|
| Static | 1.86 → 1.95 µs | 0.49 | 721 = 721 | 8 = 8 |
| Param | 4.25 → 4.42 µs | 0.70 | 1.50 Ki = | 17 = 17 |
| Query | 6.06 → 6.50 µs | 0.70 | 1.88 Ki = | 27 = 27 |
| JSONBody | 9.07 → 9.44 µs | 1.00 | 2.39 Ki = | 33 = 33 |
| Chain | 5.34 → 5.46 µs | 0.82 | 1.80 Ki = | 24 = 24 |
| Exception | 3.19 → 3.34 µs | 0.94 | 881 = 881 | 8 = 8 |
| NotFound | 1.61 → 1.66 µs | 0.70 | 673 = 673 | 5 = 5 |

- No time difference is statistically significant (every p ≥ 0.49); the geomean moved +4.4 % inside a
  ±40 % spread.
- Bytes and allocations per request are identical in every scenario.
- Step 5 measured the hook conversion alone on a quiet machine with interleaved binaries: Static 0.98,
  Chain 0.96, Invoke_Param 1.01 (after / before), and every hook that inlined before still inlines.

## Conclusion

The API review costs nothing measurable on the request path. A quiet-machine rerun of `make bench` and
`make load` belongs to the request-path performance roadmap, which starts from these numbers.
