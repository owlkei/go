# HTTP report 0009: startup and dependency lifecycle

Roadmap `docs/roadmap/0009-startup-lifecycle.md`, step 9.

## Method

`bench/` `BenchmarkGinject*` (no `AsyncImports`, so every route is ungated), test binaries of `9b50238`
(start of the roadmap) and of `b9a6458` run alternately, 8 rounds, the order swapped every round, compared
with `benchstat`. Go 1.27.4, Intel Core i7-9750H, 12 threads. The machine was busy (load average 5 to 7),
so the time spread is wide (± 10-25 %); bytes and allocations are exact.

## Results

| Scenario | 9b50238 | b9a6458 | |
|---|---|---|---|
| Static | 1.74 µs | 1.78 µs | ~ (p=0.96) |
| Param | 3.92 µs | 3.96 µs | ~ (p=0.80) |
| Query | 5.60 µs | 5.97 µs | ~ (p=0.80) |
| JSONBody | 8.23 µs | 8.59 µs | ~ (p=0.65) |
| Chain | 4.85 µs | 5.35 µs | ~ (p=0.65) |
| Exception | 2.96 µs | 3.04 µs | ~ (p=0.80) |
| NotFound | 1.46 µs | 1.50 µs | ~ (p=0.96) |
| Page JSONList | 15.2 µs | 15.1 µs | ~ (p=0.90) |
| Page PageList | 109 µs | 107 µs | ~ (p=0.65) |

- No scenario differs beyond the noise band; bytes and allocations per request are identical in every
  scenario. An ungated route pays one nil compare (HTTP) or one interface nil check (WebSocket); core
  `ServeHTTP_*` benchmarks (step 5) showed no change over 8 rounds; an open gate costs about 5-10 ns.
- Chain trended 5-7 % slower in the builder's three earlier runs, also on a busy machine; here it is
  within noise again (p=0.65). Rerun on a quiet machine before the next release measurement.
- Idle heap of a small app: 10.9 KiB → 13.0 KiB (+2.1 KiB: module states, the module table of the devtool
  snapshot); with `EnableRender` and one page 36.3 → 38.5 KiB. No goroutine runs without `AsyncImports`.
